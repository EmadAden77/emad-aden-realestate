# تفعيل الحفظ المركزي لبوابة العملاء

التنفيذ جاهز في الموقع، ويعمل تلقائيًا بالحفظ المحلي المؤقت إلى أن تُضاف قاعدة البيانات.

1. أنشئ مشروعًا مجانيًا في Supabase، ثم افتح **SQL Editor** وشغّل ملف `supabase/customer-portal.sql` كاملًا مرة واحدة.
2. في إعدادات مشروع Vercel أضف متغيري البيئة التاليين إلى Production وPreview:
   - `SUPABASE_URL`: رابط مشروع Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY` أو `SUPABASE_SECRET_KEY`: المفتاح الخادمي السري.
3. أعد نشر المشروع، ثم سجّل الدخول وأنشئ سجلًا تجريبيًا وافتح الحساب من جهاز آخر للتحقق من المزامنة.

## حماية البيانات

- لا يوضع المفتاح السري في أي ملف HTML أو JavaScript عام.
- جداول Supabase مفعّل عليها RLS، ولا توجد سياسات وصول للمتصفح.
- جميع الطلبات تمر عبر Vercel بعد التحقق من جلسة Clerk وهوية صاحب الحساب.
- تحتفظ الواجهة بنسخة محلية مؤقتة لتستمر في العمل عند انقطاع الاتصال.
